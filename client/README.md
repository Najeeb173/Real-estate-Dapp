# 🏡 Real Estate Marketplace DApp

A decentralized real estate marketplace built on Ethereum that enables users to list properties, explore available listings, purchase properties, and submit reviews through blockchain-based smart contracts.

The project demonstrates how blockchain technology can support transparent property transactions and decentralized application development.

## ✨ Features

- 🏠 **Property Listings** — Create and explore property listings.
- 💰 **Buy Properties** — Interact with smart contracts to purchase listed properties.
- 📝 **Update Listings** — Modify property information through supported contract functions.
- ⭐ **Property Reviews** — Submit reviews for properties.
- 🔗 **Wallet Integration** — Connect a compatible Ethereum wallet.
- ⛓️ **Blockchain Integration** — Interact with Ethereum smart contracts.
- 🧪 **Sepolia Testnet** — Test blockchain functionality without using real ETH.

## 🛠️ Tech Stack

| Technology | Purpose |
|---|---|
| Solidity | Smart contract development |

| React | User interface |
| JavaScript | Application logic |

## 🏗️ Architecture

The application consists of three main components:

1. **Frontend:** Provides the interface for viewing properties and interacting with marketplace features.
2. **Smart Contracts:** Handle supported property marketplace operations on the blockchain.
3. **Ethereum Network:** Stores blockchain transactions and contract state.

## 🚀 Getting Started

### Prerequisites

- Node.js and npm
- Git
- MetaMask or another compatible Ethereum wallet
- Sepolia test ETH for testnet transactions

### Installation

Clone the repository:

```bash
git clone (https://github.com/Najeeb173/Real-estate-Dapp)
cd D:\Desktop data\realstateDapp> 
```

Install dependencies:

```bash
npm install
```

Configure the required environment variables and contract deployment settings according to the project configuration.

### Run the application

```bash
npm run dev
```

Open the local development URL displayed in your terminal, usually:

```text
http://localhost:3000
```

> **Note:** Verify the available npm scripts in `package.json`. Deployment, contract compilation, and testing commands depend on your repository configuration.

## 🔐 Network Configuration
